SECTION 3.8 PYTHON CODE

Corrected ensembles and paired mechanism controls

Python 3.12; install from this folder:
  python -m pip install -r requirements.txt

Verify archived results and redraw the corrected figures:
  python run_section_3_8.py --mode verify

Recompute the scientific suite and redraw the figures:
  python run_section_3_8.py --mode full

Source mapping:
Corrected radial, energy, Saha, loading, optical and event equations: components/corrected_models/code/corrected_ensemble.py
26 ensemble cases and independent closure checks: components/corrected_models/code/run_suite.py
Fresh original-source implicit references: components/corrected_models/code/recheck_sources.py and historical_controls.py
Figure 12: components/corrected_models/code/make_figures.py
Table 6 and refinement values: components/corrected_models/results/corrected_ensemble_controls.csv and corrected_ensemble_convergence.csv

The shared suite also contains phase_change.py, eight phase cases, Figure 13 and Table 7. These belong to Section 3.9 in the reorganized manuscript; earlier drafts grouped them under 3.8. They are separate existing-cavity calculations, not a modification of the original Figures 2–7.

Archived summaries and arrays needed to redraw the figures are supplied. Some ancillary trajectory archives are omitted and regenerated by --mode full. Full sweeps can take several minutes. The original archived solver scripts are preserved byte-for-byte; the top-level runner is a separate packaging utility. Numerical verification is not experimental validation of plasma, quenching or optical flashes.
