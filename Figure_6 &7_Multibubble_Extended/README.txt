Figure 6 reproducibility package

1. Install numpy and matplotlib.
2. Run python export_figure.py to reproduce and save both plots, numerical results and diagnostics.
3. Or run python multibubble_full_extended.py to display the original two plots.

The provided original code is copied without changes. The exporter calls the original simulate and plot_all functions with the original main() arguments.
The model-generated bursts and ionization are proxies, not direct optical measurements or independently validated plasma outcomes.
